# Airframe

Airframe turns a design system into a tool: tokens as typed source files, with tiers and ownership enforced at the consumer (every platform's code, not just the token file), generated native outputs for each platform (CSS, Swift, Kotlin/Compose, C#/XAML, and a neutral JSON contract), and a reference surface for asking which token to use here and whether a file may read it.

Airframe is a Go CLI. It is a sibling of Starboard (screens and flows) and Gantry (decisions, defects, evidence).

Pre-release. Nothing here is stable yet.
