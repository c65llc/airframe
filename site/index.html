Design tokens

Airframe is a Go CLI for defining, checking, and building design tokens from a typed source.

Get started View on GitHub
$ airframe lint --json

A single source for
your design tokens.

Define the source

Write typed tokens in DTCG JSON. Organize them into primitive, semantic, and component tiers, with explicit axes for modes like appearance and density.

Catch drift in CI

Check tier boundaries, alias types, contrast floors, and stale generated files. Use a machine-readable verdict to gate changes in CI.

Build CSS and JSON

Generate CSS custom properties scoped to each mode and a JSON contract with resolved values, all from the same source.

From source
to build.

Initialize a starter project, check the token source, and generate CSS and JSON. Install with Go or download a release.

Quick start
  1. $ go install github.com/c65llc/airframe/cmd/airframe@latest
  2. $ airframe init
  3. $ airframe lint
  4. $ airframe build
